# 🚀 Tool Đếm Ngón Tay Tự Động bằng Python

📄 **Mô tả**  
**Counting_Fingers** là công cụ nhận diện ngón tay trên video sử dụng thư viện **Mediapipe** của Google. Công cụ giúp bạn đếm số ngón tay trong thời gian thực qua webcam, với khả năng nhận diện chính xác số lượng ngón tay ngay cả khi các ngón tay có thể bị che khuất.

⚠️ **Lưu ý quan trọng**
- Công cụ này chỉ sử dụng cho mục đích học tập và nghiên cứu.
- Hãy đảm bảo bạn sử dụng trong môi trường hợp pháp và đúng mục đích.

🛠️ **Yêu cầu**
- Python 3.x
- Thư viện **OpenCV** và **Mediapipe**

📥 **Clone dự án**  
Để tải và sử dụng công cụ, bạn chỉ cần clone dự án về máy của mình:

```bash
git clone https://github.com/haivoDA22TTD/Counting_Fingers.git
cd Counting_Fingers
```
## 🪟 Windows

## Cài đặt các thư viện phụ thuộc:
```bash
pip install opencv-python mediapipe
```

## Chạy tool:
```bash
python Counting_Fingers.py
```
## 🍎 macOS

Cài Python (nếu chưa có): Tải Python cho macOS

### Cài đặt thư viện cần thiết:

pip3 install opencv-python mediapipe


## Chạy tool:
```bash

```
